# EasyFK Component 项目说明文档

> 企业级 Java 微服务基础组件库：按需组合、开箱即用、统一规范，帮助团队快速构建高可用业务系统。

## 一、项目介绍

`easyfk-component` 是 EasyFK 框架的基础设施组件仓库，基于 `Spring Boot 3.2.x` 与 `Java 21` 构建，覆盖数据访问、ORM、消息队列、RPC、缓存、分布式事务、实时通信、安全治理等核心能力。

项目采用多模块 Gradle 架构，组件可独立引入、按业务场景自由组合，具备统一依赖管理（BOM）、统一配置风格、统一接口体验，显著降低项目落地门槛与团队协作成本。

## 二、宣传级核心卖点

- 一站式基础设施：从数据库到消息、从 RPC 到 WebSocket，全链路覆盖
- 强可插拔能力：模块化拆分，按需引入，避免“大而全”架构负担
- 统一开发体验：跨 ORM/MQ/存储保持一致 API 设计，迁移成本低
- 生产级稳定性：内置自动配置、连接池管理、异常隔离与优雅关闭机制
- 高性能导向：Netty + Disruptor、Kafka Streams、Caffeine、Chronicle 等技术组合
- 生态兼容广：深度适配 Spring Cloud Alibaba、Dubbo、ShardingSphere、Seata

## 三、技术架构特色

### 1) 统一工程能力

- 统一版本：`com.mcst:easyfk-dependencies:3.2.12`
- 统一配置：`easyfk.config.*` 前缀，声明式配置，便于运维管理
- 统一装配：基于 Spring Boot AutoConfiguration，引入依赖即可生效
- 统一规范：接口模型与参数模型标准化，跨模块学习成本低

### 2) 高性能与高可用设计

- 实时通信：`websocket-server` 基于 Netty 与 Disruptor，支持高并发推送
- 本地缓存：`cache-caffeine` 提供高性能内存缓存与多策略淘汰
- 海量分析：`db-clickhouse` 面向大规模分析场景，支持批量写入与复杂条件查询
- 消息处理：`mq-kafka` 支持 Kafka Streams 流处理与高吞吐消息链路
- 分布式治理：`protect-sentinel`、`transaction-seata` 支撑稳定与一致性

## 三、各组件详解

### 3.1 数据持久层（ORM）

#### orm-mybatis

**定位**：基于 MyBatis-Plus 的默认 ORM 组件，实现框架统一的 `IBaseRepository` 接口。

**技术栈**：MyBatis-Plus、Spring Boot 3.x

**核心亮点**：
- 完整的 CRUD、分页查询、智能条件构建（等值/模糊/IN/区间/NULL/自定义 SQL）
- 自动填充时间字段、逻辑删除、DTO/PO 自动转换
- 防全表更新/删除、数据库类型自动识别
- 与 `SearchCondition` 统一查询条件深度集成

---

#### orm-flex

**定位**：基于 MyBatis-Flex 的高性能 ORM 组件，API 与 orm-mybatis 完全对齐。

**技术栈**：MyBatis-Flex 1.11.4、Spring Boot 3.x

**核心亮点**：
- **零依赖、零拷贝**，查询性能远超 MyBatis-Plus
- 与 orm-mybatis 接口完全兼容，**更换基类即可迁移**，业务代码零改动
- 六类条件构建、自动填充、逻辑删除、智能 deleteById（支持单个/逗号/集合）
- 双实体基类（完整版/简化版）按需选择

---

#### orm-hibernate

**定位**：基于 Hibernate/JPA 的 ORM 实现，面向 JPA 标准生态。

**技术栈**：Hibernate、Spring Data JPA

**核心亮点**：
- 实现 `IBaseRepository` 统一接口，与 orm-mybatis/orm-flex 无缝切换
- JPA 注解驱动，支持复杂关联关系映射
- 面向 JPA 原生生态的开发者

---

#### orm-sharding

**定位**：透明分库分表组件，业务代码零改动。

**技术栈**：Apache ShardingSphere JDBC

**核心亮点**：
- **纯 YAML 配置**实现分库分表、读写分离、数据加密
- 与 orm-mybatis、orm-flex 完全兼容，Repository 零修改
- 多种分片算法（HASH_MOD、范围、行表达式）、雪花算法主键
- 一主多从、负载均衡、事务内自动走主库

---

### 3.2 数据访问层（DB）

#### db-redis

**定位**：企业级 Redis 高级数据访问组件，一套组件驾驭所有 Redis 场景。

**技术栈**：Lettuce、Commons Pool2、Spring Data Redis

**核心亮点**：
- **动态多数据源** + 多数据库 + 命名空间三级隔离
- 单机/集群/哨兵全覆盖，零代码切换
- 智能序列化器（Jackson/FastJSON/Kryo）+ 历史数据自动兼容
- 五大数据结构 60+ 方法、Pipeline/事务/Lua 脚本、Pub/Sub + 指数退避重试 + 死信队列

---

#### db-mongo

**定位**：MongoDB 文档数据库访问组件，文档即对象。

**技术栈**：Spring Data MongoDB、MongoTemplate

**核心亮点**：
- 三层架构（Entity → DAO → Repository），DTO ↔ Entity 自动转换
- 智能 ID 管理（ObjectId 与 String 互转）、全自动审计（createdAt/updatedAt）
- 十种查询条件 + 链式 API、全量/增量/条件/upsert 四种更新策略
- 批量插入自动分批（1000 条/批）、原子递增

---

#### db-influx

**定位**：InfluxDB 时序数据库访问组件。

**技术栈**：InfluxDB Java Client、Flux 查询语言

**核心亮点**：
- `IBaseFluxRepository` 统一接口，支持 CRUD、条件查询、时间范围删除
- `FluxSearchCondition` 相对时间表达式（-12h、-30m 等）
- 面向 IoT、监控、日志等时序数据场景

---

#### db-clickhouse

**定位**：ClickHouse 列式数据库访问组件，驾驭海量数据分析。

**技术栈**：ClickHouse JDBC、HikariCP

**核心亮点**：
- 注解驱动映射（@ClickHouseTable、@ClickHouseColumn）
- 十余种条件类型 + 相对时间表达式、聚合分组、FINAL 去重
- 智能分批批量写入、SQL 注入防护 + 误删/误更新保护
- 与 SearchRequest 一键转换，延迟初始化、独立于主数据源

---

### 3.3 消息队列（MQ）

#### mq-common

**定位**：统一消息模型层，跨 MQ 引擎一致体验。

**技术栈**：Java、Protobuf

**核心亮点**：
- `CommonMessage<T>`、`ProtobufMessage<T>` 统一消息载体
- 消息 ID、标签、时间戳、delayTime、messageKey 等通用字段
- Kafka/RabbitMQ/RocketMQ 三大引擎**业务代码零改动**切换

---

#### mq-rocket

**定位**：RocketMQ 消息队列组件，金融级可靠、顺序保证。

**技术栈**：Apache RocketMQ、Spring Boot Starter

**核心亮点**：
- 三种消息类型自动识别：普通/延迟（毫秒级）/顺序
- Tag 过滤、同步+异步双模发送、双层 API（RocketProducer / RocketProducerHelper）
- 一个 API 自动路由，零手动切换

---

#### mq-rabbit

**定位**：RabbitMQ 消息队列组件，灵活路由、可靠投递。

**技术栈**：Spring AMQP、RabbitMQ

**核心亮点**：
- CommonMessage 智能映射为 Exchange/RoutingKey
- delayTime > 0 自动走延迟交换机（rabbitmq_delayed_message_exchange 插件）
- Confirm + Return 双回调、Jackson JSON 自动序列化

---

#### mq-kafka

**定位**：Kafka 消息队列组件，百万级吞吐、流批一体。

**技术栈**：Spring Kafka、Kafka Streams

**核心亮点**：
- **JSON + Protobuf 双序列化通道**，按场景选择最优方案
- 幂等发送 + 批量聚合 + Snappy 压缩，百万级 TPS
- `BaseStreamProcessor` + `StreamProcessorRegistry` + SerdeFactory，Kafka Streams 开箱即用

---

### 3.4 缓存（Cache）

#### cache-caffeine

**定位**：高性能本地缓存组件，基于 Caffeine。

**技术栈**：Caffeine、Spring Cache

**核心亮点**：
- 四种缓存类型：Cache、LoadingCache、AsyncCache、AsyncLoadingCache
- W-TinyLFU 淘汰算法、写后/读后过期、写后异步刷新
- 弱引用/软引用缓存、编程式 + 注解式双模式、内置统计监控

---

#### cache-redis

**定位**：Redis 分布式缓存组件。

**技术栈**：Spring Data Redis、db-redis

**核心亮点**：
- 基于 db-redis 构建，作为分布式缓存层

---

### 3.5 高性能本地存储（Chronicle）

#### chronicle-map

**定位**：堆外高性能键值存储，零 GC 影响。

**技术栈**：Chronicle Map、内存映射文件（mmap）

**核心亮点**：
- **Off-Heap 堆外存储**，大容量缓存不受 GC 影响
- 亚微秒级读写、文件持久化、进程重启自动恢复
- 类型安全、读写锁优化、ChronicleMapTemplate 简洁 API
- YAML 声明式创建 Map、固定尺寸类型优化

---

#### chronicle-queue

**定位**：基于 Chronicle Queue 的高性能消息队列。

**技术栈**：Chronicle Queue

**核心亮点**：
- 持久化、低延迟、适合进程内/进程间消息传递
- 与 Chronicle Map 同属 Chronicle 生态

---

### 3.6 实时通信（WebSocket）

#### websocket-server

**定位**：基于 Netty 的实时通信基础设施，高并发、低延迟。

**技术栈**：Netty、LMAX Disruptor、Caffeine

**核心亮点**：
- **Netty 异步非阻塞**、Boss/Worker 分离、业务线程池隔离
- **Disruptor 无锁队列**、分片设计、零拷贝广播

- 频道订阅体系、拦截器链式认证、JWT + HMAC-SHA256、多端会话管理
- 智能心跳、运行时监控、优雅关闭

### 3.7 远程调用（RPC）

**定位**：高性能 RPC 调用，上下文无缝透传。

## 四、技术特色与亮点总结

### 4.1 统一 API 设计

- **IBaseRepository**：orm-mybatis、orm-flex、orm-hibernate、db-mongo 均实现同一接口，**业务层零感知底层存储**
- **SearchCondition**：统一查询条件构建器，跨 ORM、db-clickhouse、db-mongo 复用
- **CommonMessage**：mq-rocket、mq-rabbit、mq-kafka 统一消息模型，**切换 MQ 引擎零改动**

### 4.2 开箱即用

- 所有组件基于 **Spring Boot AutoConfiguration**，引入依赖即自动装配
- `@ConditionalOnMissingBean` 支持业务自定义覆盖
- 配置项统一 `easyfk.config.*` 前缀，YAML 声明式配置

### 4.3 企业级能力

- **链路追踪**：rpc-dubbo、rpc-cloud 自动透传 TraceId
- **业务异常透传**：rpc-cloud FeignErrorDecoder 原样传递 code/msg
- **安全防护**：websocket JWT + HMAC-SHA256、db-clickhouse SQL 注入防护
- **优雅关闭**：db-redis、websocket 等组件 DisposableBean 资源释放

### 4.4 高性能设计

- **WebSocket**：Netty + Disruptor + 零拷贝广播
- **db-redis**：Pipeline、Lua 脚本、智能序列化
- **mq-kafka**：百万级 TPS、Kafka Streams 流处理
- **chronicle-map**：堆外存储、零 GC 影响
- **cache-caffeine**：W-TinyLFU、LoadingCache 防穿透

### 4.5 生态融合

- 组件间相互依赖：cache-redis 依赖 db-redis，autoId-redis 依赖 db-redis
- 统一返回值：BaseResult、PageResult 贯穿全框架
- 统一 BOM：easyfk-dependencies 3.2.12 统一版本管理
